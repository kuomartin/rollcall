# 每位主辦方部署自己的試算表副本

最終使用者是其他主辦方，名單在他們自己的試算表裡。集中部署一份 Web App 的話，它以部署者的身分執行，只讀得到部署者有權限的試算表：要嘛每位主辦方把試算表分享給部署者（所有人的名單都經過同一個帳號，Apps Script 同時執行數也由所有活動共用），要嘛做不到。所以範本試算表綁定完整的 Apps Script，主辦方複製後自己部署成網頁應用程式，以自己的身分執行、只服務自己那份試算表。

## Consequences

- 程式更新推送不到別人的副本。要新版就重新複製範本；活動是短期的，版本固定反而好預測。
- 沒有註冊流程，也不需要活動 token：部署 ID 本身就指向那份試算表（見 ADR-0002）。
