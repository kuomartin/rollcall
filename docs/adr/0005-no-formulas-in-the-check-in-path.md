# 報到紀錄與學員名單不放公式，衍生欄位由程式寫入

舊版在報到分頁用公式展開學員資料、在學員名單用公式算最近報到時間。實測 800 人、600 筆報到時，8 個入口同時報到每筆要 1–15 秒、全部完成 37 秒；拿掉公式後同樣條件每筆 1–3 秒。原因是每次寫入都觸發 O(名單 × 報到) 的重算（其中一條用了 volatile 的 `INDIRECT`），再加上 lock 排隊。所以寫入報到紀錄時直接把學員欄位的快照一起寫入（要哪些欄位由報到分頁的標題列決定，沿用舊公式的語意），學員名單的「{場次} 報到時間」欄由程式維護。

## Consequences

- 快照是報到當下的值：之後修改學員名單，已寫入的報到紀錄不會跟著變。
- 不要為了方便在報到分頁或學員名單加上依賴對方的整欄公式，延遲會回來。
